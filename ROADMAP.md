# Roadmap

Planned work is grouped by priority. Items are proposals and may change as the project evolves.

## Next

- **Dialog log:** Add an optional history of recent bot lines and per-bot portrait expressions that change with the event (cheering, groaning).
- **Dark/light UI mode:** Add a dark/light toggle for the app chrome (board themes are already selectable) and remember the preference.
- **Richer audio:** Optionally replace synthesized sounds with recorded assets, add a second background track, and add short UI sounds for menus.

## Later

- **Online multiplayer:** Support remote players using WebSockets, synchronized turns, and reconnect handling.
- **Room management:** Add private game rooms, invite links, and player-ready state for online matches.
- **Dialog enhancements:** Add player-side quick reactions (emotes, not typed text), a dialog speed setting, and more lines per event.

## Quality

- Add automated tests for game rules, turn handling, event triggers, dialog queue behavior, and settings sanitizing (layout mode).
- Review keyboard navigation, screen-reader announcements, and small-screen layouts as features expand.
